# Roblox: волны зомби

## Что получится

- зомби появляются рядом с одним Part;
- зомби бегут к ближайшему игроку и атакуют его;
- после уничтожения всех зомби начинается новая волна;
- следующие волны становятся сложнее;
- на каждой пятой волне появляется босс;
- на экране показывается номер волны;
- в таблице показываются убийства и смерти.

---

# Шаг 1. Подготавливаем зомби

1. В `Workspace` переименуйте готового зомби в `Zombie`.
2. Перетащите `Zombie` в `ServerStorage`.
3. Откройте модель `ServerStorage → Zombie`.
4. Удалите из зомби старый объект с названием `Script`.
5. Удалите старый `Sound`, если он есть.

Это уберёт ошибки:

```text
Torso is not a valid member
Failed to load sound rbxassetid://90
```

---

# Скрипт 1. ZombieAI

1. Нажмите правой кнопкой по `ServerStorage → Zombie`.
2. Выберите **Insert Object → Script**.
3. Назовите новый скрипт `ZombieAI`.
4. Вставьте весь код:

```lua
local Players = game:GetService("Players")

local zombie = script.Parent

-- true позволяет искать детали даже внутри вложенной модели.
local humanoid = zombie:FindFirstChildWhichIsA("Humanoid", true)

local root = zombie:FindFirstChild("HumanoidRootPart", true)
    or zombie:FindFirstChild("UpperTorso", true)
    or zombie:FindFirstChild("Torso", true)

if not humanoid or not root then
    warn("У зомби нет Humanoid или части тела")
    return
end

local DAMAGE = 10
local ATTACK_DISTANCE = 4
local ATTACK_DELAY = 1
local canAttack = true

local function getNearestPlayer()
    local nearestPlayer = nil
    local nearestDistance = 200

    for _, player in Players:GetPlayers() do
        local character = player.Character

        if character then
            local playerHumanoid = character:FindFirstChildOfClass("Humanoid")
            local playerRoot = character:FindFirstChild("HumanoidRootPart")

            if playerHumanoid and playerRoot and playerHumanoid.Health > 0 then
                local distance = (root.Position - playerRoot.Position).Magnitude

                if distance < nearestDistance then
                    nearestDistance = distance
                    nearestPlayer = player
                end
            end
        end
    end

    return nearestPlayer, nearestDistance
end

humanoid.Died:Connect(function()
    -- Для простого урока очко получает ближайший игрок.
    local player = getNearestPlayer()

    if player and player:FindFirstChild("leaderstats") then
        player.leaderstats.Kills.Value += 1
    end

    task.wait(2)
    zombie:Destroy()
end)

while humanoid.Health > 0 do
    local player, distance = getNearestPlayer()

    if player and player.Character then
        local playerRoot = player.Character:FindFirstChild("HumanoidRootPart")
        local playerHumanoid = player.Character:FindFirstChildOfClass("Humanoid")

        if playerRoot and playerHumanoid then
            humanoid:MoveTo(playerRoot.Position)

            if distance <= ATTACK_DISTANCE and canAttack then
                canAttack = false
                playerHumanoid:TakeDamage(DAMAGE)

                task.delay(ATTACK_DELAY, function()
                    canAttack = true
                end)
            end
        end
    end

    task.wait(0.2)
end
```

# Шаг 2. Создаём место появления

1. Добавьте в `Workspace` обычный **Part**.
2. Назовите его `ZombieSpawn`.
3. Перетащите Part мышкой на землю рядом с крепостью.
4. В `Properties` включите `Anchored`.
5. Выключите `CanCollide`.
6. Поставьте `Transparency = 0.5`.

Зомби будут появляться рядом с этим Part.

# Скрипт 2. Волны внутри ZombieSpawn

1. Нажмите правой кнопкой по `Workspace → ZombieSpawn`.
2. Выберите **Insert Object → Script**.
3. Назовите скрипт `Waves`.
4. Вставьте весь код:

```lua
local ServerStorage = game:GetService("ServerStorage")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local spawnPart = script.Parent
local zombieTemplate = ServerStorage:WaitForChild("Zombie")

local waveValue = ReplicatedStorage:FindFirstChild("Wave")
    or Instance.new("IntValue")
waveValue.Name = "Wave"
waveValue.Parent = ReplicatedStorage

local aliveValue = ReplicatedStorage:FindFirstChild("ZombiesAlive")
    or Instance.new("IntValue")
aliveValue.Name = "ZombiesAlive"
aliveValue.Parent = ReplicatedStorage

local wave = 0

local function createZombie(number, amount)
    local zombie = zombieTemplate:Clone()
    local humanoid = zombie:FindFirstChildWhichIsA("Humanoid", true)

    if not humanoid then
        warn("В модели Zombie нет Humanoid")
        zombie:Destroy()
        aliveValue.Value = math.max(aliveValue.Value - 1, 0)
        return
    end

    -- Зомби становится сильнее с каждой волной.
    humanoid.MaxHealth = 100 + wave * 20
    humanoid.Health = humanoid.MaxHealth
    humanoid.WalkSpeed = math.min(8 + wave, 18)

    -- Последний зомби каждой пятой волны становится боссом.
    if wave % 5 == 0 and number == amount then
        zombie.Name = "BOSS"
        humanoid.MaxHealth *= 5
        humanoid.Health = humanoid.MaxHealth
        humanoid.WalkSpeed = 7
    else
        zombie.Name = "Zombie"
    end

    zombie.Parent = workspace

    -- Появление рядом с Part.
    local randomX = math.random(-8, 8)
    local randomZ = math.random(-8, 8)
    local spawnPosition = spawnPart.CFrame
        * CFrame.new(randomX, 4, randomZ)

    zombie:PivotTo(spawnPosition)

    humanoid.Died:Once(function()
        aliveValue.Value = math.max(aliveValue.Value - 1, 0)
    end)
end

while true do
    -- Отдых перед волной.
    task.wait(10)

    wave += 1
    waveValue.Value = wave

    local amount = 3 + (wave - 1) * 2
    aliveValue.Value = amount

    for number = 1, amount do
        createZombie(number, amount)
        task.wait(1)
    end

    -- Следующая волна ждёт уничтожения всех зомби.
    repeat
        task.wait(1)
    until aliveValue.Value == 0
end
```

> Удалите старые `ZombieSpawner` и `Waves` из `ServerScriptService`. Теперь волнами управляет только скрипт внутри `ZombieSpawn`.

# Скрипт 3. PlayerStats

1. Нажмите правой кнопкой по `ServerScriptService`.
2. Выберите **Insert Object → Script**.
3. Назовите его `PlayerStats`.
4. Вставьте весь код:

```lua
local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
    local leaderstats = Instance.new("Folder")
    leaderstats.Name = "leaderstats"
    leaderstats.Parent = player

    local kills = Instance.new("IntValue")
    kills.Name = "Kills"
    kills.Parent = leaderstats

    local deaths = Instance.new("IntValue")
    deaths.Name = "Deaths"
    deaths.Parent = leaderstats

    player.CharacterAdded:Connect(function(character)
        local humanoid = character:WaitForChild("Humanoid")

        humanoid.Died:Connect(function()
            deaths.Value += 1
        end)
    end)
end)
```

# Скрипт 4. Надпись с волной

1. Откройте `StarterPlayer → StarterPlayerScripts`.
2. Добавьте **LocalScript**.
3. Назовите его `WaveText`.
4. Вставьте весь код:

```lua
local player = game.Players.LocalPlayer
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local wave = ReplicatedStorage:WaitForChild("Wave")
local alive = ReplicatedStorage:WaitForChild("ZombiesAlive")

local gui = Instance.new("ScreenGui")
gui.ResetOnSpawn = false
gui.Parent = player:WaitForChild("PlayerGui")

local text = Instance.new("TextLabel")
text.Size = UDim2.new(0, 420, 0, 70)
text.Position = UDim2.new(0.5, -210, 0, 20)
text.BackgroundColor3 = Color3.fromRGB(30, 30, 30)
text.BackgroundTransparency = 0.2
text.TextColor3 = Color3.fromRGB(255, 255, 255)
text.TextScaled = true
text.Parent = gui

local function updateText()
    if wave.Value == 0 then
        text.Text = "Первая волна через 10 секунд"
    else
        text.Text = "Волна: " .. wave.Value
            .. "     Зомби: " .. alive.Value
    end
end

wave.Changed:Connect(updateText)
alive.Changed:Connect(updateText)
updateText()
```

# Запускаем

1. Нажмите **Play**.
2. Подождите 10 секунд.
3. Рядом с `ZombieSpawn` появятся 3 зомби.
4. После их уничтожения начнётся следующая волна.
5. На пятой волне появится босс.
